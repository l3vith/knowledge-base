# Task worksheet implementation

This iteration implements the query-time worksheet path in the existing synthesis mode. It keeps Qwen thinking disabled and GLM 5.3 Flash as the independent judge. It does not claim an accuracy gain until the fresh development benchmark is scored.

- The existing planning call proposes query-anchored operations and required source roles. Code validates literal anchors, operation types, IDs and bounds; missing tasks get generic query-derived defaults. Source-role searches get independent retrieval/triage queues. Acronym hints come only from definitions in retrieved source text and remain alternatives.
- All verified writer-visible spans are eligible. The fact inventory suggests candidates; it no longer vetoes findings. Worksheet writers do not have mandatory fact restoration or a second generic appraisal writer. Legacy taskless fixtures retain their source-copy fallback for compatibility.
- The same writer call returns linked source inputs and operation outcomes. Code resolves document/page/section/offsets, copies exact quotes, and checks source-owned entity/metric/period/unit/basis values. Missing scope stays unknown. Mismatched scope is incomparable; numeric comparisons with unresolved scope fail before the semantic checker. A deliberate varying field must be requested in the literal query anchor.
- Final verification independently checks claim support and whether the requested operation was performed. Faithful but nonresponsive summaries cannot establish completion. Worksheet/coverage details stay inside existing traces/artifacts and response coverage.
- Factual screening accepts relevant explanations, counterevidence and qualifications without treating their incidental numbers as answers. An initial tranche and reserve can be followed by at most two recovery batches from already retrieved candidates, prioritizing possible explanatory source language. Every retained fragment still passes model verification. A verified direct value stops recovery; explanations alone do not. Existing call, byte, deadline and monetary admission limits still apply. There is no unlimited rescan or arbitrary context fallback.
- **Follow-up, after the measured C32/C26 run:** evidence verification now uses adaptive Qwen selection by default. After each checked batch, the selector sees unresolved query tasks, a bounded summary of verified evidence, and previews of the full remaining candidate pool, then chooses the next IDs. Only locally known IDs are accepted, and every chosen span still goes through the exact source verifier. A task can stop the search only when the verifier tagged enough distinct source fragments for it (two for compare/reconcile/assess, one for lookup/inspect/absence) and the selector also marks it covered. A direct verified numeric answer still stops a narrow factual query. The selector is bounded by the existing query/call/byte budgets, eight analytical batches, or four factoid batches. Its Qwen call uses the existing configured answer model without enabling reasoning. This follow-up has syntax-checked code but has not been run on C32/C26; it is not included in the metrics below.
- Explanatory factoids use checked synthesis instead of clipping evidence down to a numeric clause. Public coverage includes verified, remaining, budget-omitted and recovery counts; partial inspection never proves document-wide absence.
- A checker may identify a query-relevant source core behind an unsupported *finding phrase*. At most four exact-source cores receive one additional semantic-check call. Wrong scopes, background, unsupported premises, interpretations and gaps are ineligible. Failed/budget-denied repair never retries or auto-approves a copied quote. Structured original verdict reasons and repair counts remain visible.

Scope limits: no global graph, new database, retriever training, visual interpretation, or model/thinking switch. Recovery consumes existing promising candidates; there is no additional dynamic external retrieval loop. Query-time scope alignment is conservative and may leave useful but underspecified comparisons unresolved. The two requested cases are development cases already inspected during diagnosis; the combined iteration is not a causal ablation of each component.

Offline regressions cover advisory selection, semantic rejection, negative evidence, bounded recovery/stopping, immutable provenance, scope mismatch/unknowns, deterministic calculation guards, operation completion and one-call repair. Existing route, trace, source-isolation, citation and budget regressions remain required. Fresh C32/C26 results will be recorded separately with the measured commit and complete costs.

The first live pass exposed a scheduling defect: the planner could legitimately take longer than the fixed cumulative 16.5-second verification cutoff, so C26 admitted no evidence checks. Verification now uses the *remaining* 30-second early-stage deadline; the actual deadline, token/call caps and final-stage grace are preserved. An offline clock regression covers both admission after slow planning and denial after actual expiry. The initial pass is preserved, and one corrective pass carries its full prior cost into the same aggregate $0.10 ledger.
